1. Install dependencies, open CMD and run:
```pip install flask yt-dlp```
   
2. File Structure (Create a folder named Meow):
/Meow/
├── app.py
|── downloads
└── templates/
    └── index.html

3. In CMD navigate to your folder and run:
```cd path/to/MyProject```
```python app.py```

4. Run ```http://127.0.0.1:5000``` in browser
